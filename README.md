# Projet BD6 - RunTogether

**Contenu de l'archive :**

* `schema.sql` : Script de nettoyage et de création des tables (avec contraintes).
* `insert.sql` : Script d'importation des données depuis les fichiers CSV.
* `requetes.sql` : Les 20 requêtes SQL et l'algorithme de recommandation.
* `bdd.py` & `CSV/` : Script Python générateur de données et les 14 fichiers de données.
* `Rapport_RunTogether.pdf` : MCD, schéma relationnel et explications.

**Instructions d'exécution (dans psql) :**

1. `\i schema.sql`
2. `\i insert.sql`
3. `\i requetes.sql`
